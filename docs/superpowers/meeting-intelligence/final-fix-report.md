# Final whole-branch fix report

This report records the implementation response to the 12 Important and two Minor findings in `final-review.md`. The implementation retained existing tenant/owner checks, fixed meeting scopes, generation and lease guards, source immutability, quota reservations, and stale-answer publication checks. No Prisma schema change was needed; migration count remains 43.

## Finding dispositions

- **F1 — fixed.** Tencent originals and supplemental files now share SHA-256 active-file identity. Tencent artifact IDs remain in provenance metadata. The source-service regression performs an actual original import followed by a renamed byte-identical supplement; cross-meeting identical content and historical draft reupload rules remain covered.
- **F2 — fixed.** Runtime `REINDEX` dispatch uses the guarded source-processing path. The SQLite integration regression runs the actual job runner through an embedding failure and checks the failed meeting/job state and superseded-generation protection.
- **F3 — fixed.** Worker-side transcript clipping validates full duration from the recording timeline origin, selected interval bounds, timestamp integrity, and authoritative duration before parse/publication. Recording duration remains independent of first speech; a late first segment in a four-hour recording still fails the full-transcript three-hour limit. A selected silent interval can remain valid when it is within known recording duration and the whole-meeting summary supplies content.
- **F4 — fixed.** Meeting coverage persists normalized capability state, full/selected transcript scope, whole-meeting summary inclusion, and selected/excluded attachment IDs and names. Confirmation, center, detail, and citation coverage render from the saved record; signed download URLs are excluded.
- **F5 — fixed.** Tencent `error_info.error_code` is decoded, including confirmed absence and permission/transient errors. Public errors remain generic and credential/URL redaction remains in place.
- **F6 — fixed per the approved PRD.** Unknown stays unknown. Missing capability configuration is also treated as unknown. Metadata-only success requires explicit administrator-confirmed unsupported capability or Tencent-confirmed absence; configured supported APIs that fail do not silently degrade. Admin confirmation records administrator ID and time. The UI and deployment guide now describe this policy.
- **F7 — fixed.** PPTX slide positions follow `presentation.xml` order through its relationship IDs. Native text and OCR citations use displayed one-based positions; missing or invalid ordering metadata fails parsing instead of fabricating positions from filenames.
- **F8 — fixed.** OCR defaults to a 120,000 ms deadline, configurable from 5,000 to 300,000 ms. The deadline covers response headers and complete JSON body reading, aborts the request, and fails the durable job; a regression proves the next queued job can run. This bounds how long one slow OCR operation can hold the worker. A low setting can reject legitimate slow work; a high setting can delay later jobs up to five minutes. These are operational bounds, not measured latency or quality claims.
- **F9 — fixed.** Workspace retrieval validates provider envelopes and rejects explicit provider failures. A Lance-shaped “namespace missing” response is a controlled retrieval error when documents are persisted; truly empty workspaces and valid no-hit searches remain empty results. Current document membership and ACL lookup remain required before emitting evidence.
- **F10 — fixed.** Retrieved meeting evidence carries the meeting title and start date into the prompt and saved citation. Citation UI falls back to those frozen values when a meeting is unavailable or deleted. QA history and rendered-component regressions cover the historical case.
- **F11 — fixed.** The owner-filtered conversation list API and center links allow reopening saved sessions, including unavailable scopes. Detail starts a session with only the current meeting and no workspaces. Explicit Workspace selection remains available in the meeting-center scope flow, whose default selection is empty. Existing owner and current-access checks continue to gate reopening and use.
- **F12 — fixed.** Import jobs persist `FETCHING`, `PARSING_OCR`, `INDEXING`, `PUBLISHING`, and terminal stages. Failed rows show the current stage and error independently.
- **M1 — fixed.** Admin config returns `secretIdPresent`, `secretKeyPresent`, and `stsTokenPresent` booleans instead of masked secret suffixes. Employee config projection remains limited.
- **M2 — fixed.** Exclusive JSON records are written to a private temporary file and atomically published with a same-directory hard link. A concurrent identical binding can safely read the completed winner; the same-binding concurrency regression passes.
