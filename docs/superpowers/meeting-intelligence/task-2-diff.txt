+# Task 2 implementation report
+
+## Delivered
+
+Implemented the Tencent Meeting client, encrypted connection configuration, durable job runner, and meeting importer in `server/modules/meetings/`. The client signs requests for the fixed Tencent Meeting API host, applies request timeouts, redacts credentials and response bodies from errors, paginates meeting and recording results, and only downloads artifacts from Tencent-returned HTTPS URLs. Download handling checks advertised length and streams with a hard byte ceiling before buffering.
+
+The client exposes `describeMeeting(externalId, { startTime, endTime })` for preflight. It shares recording discovery with content retrieval and returns attachment IDs, names, artifact types, byte-size availability, per-file limit, transcript duration, recording metadata, and capability states. Signed download URLs are never included in the manifest. Since Tencent's detail response does not document artifact byte sizes, `bytes` is `null`; `maxBytes` is provided.
+
+Content capability defaults are explicit: transcript, summary, and downloadable attachments are `unsupported` until enabled in connection configuration, with a manual-supplement reason. A confirmed per-record absence is reported as `absent`. Configured-supported runtime failures propagate and fail the job. Transcript absence handles only documented per-item no-content/not-found codes; generation-in-progress and other errors remain failures. No undocumented endpoint or arbitrary business-file API is assumed.
+
+Connection credentials are encrypted before persistence and omitted from public responses and audit events. Import reservation checks duplicates and quarterly capacity transactionally. Import jobs persist the selected metadata and scope, use an exclusive renewable lease that can be reclaimed after expiration, and clear their active reservation on terminal success or failure. Retry reacquires the same active key and rechecks duplicate and quota conditions. The reservation key is exactly `${connectionId}:${trimmedExternalId}`, matching the meeting deduplication key.
+
+Import scope uses `scope.startTime` and `scope.endTime` for the Tencent meeting-discovery date window (at most 90 days). `scope.from` and `scope.to` are elapsed millisecond offsets into the normalized transcript timeline; zero is valid, and the selected interval is validated from these actual bounds against the three-hour cap. When bounds are supplied, transcript paragraphs are clipped by overlap; transcript selection fails if the provider supplies no timestamps. `scope.attachmentIds` selects external artifact IDs; omitted means all supported returned artifacts. The summary is retained whole. Attachment downloads enforce 100 MB per file, 20 files, and 500 MB total.
+
+Tencent paragraph timestamps are relative to each recording file, not the meeting epoch. Multiple recording files are placed on one meeting timeline by offsetting each paragraph with the file's `record_start_time` relative to the earliest file start; the original `recordFileId` is retained in each transcript segment's `location`. The preflight manifest reports each recording's normalized start offset and duration. This prevents applying a fresh three-hour allowance independently to each recording.
+
+If no supported content is present because capabilities are explicitly unsupported or content is absent, the importer creates a metadata-only `DRAFT`/`WAITING_CONTENT` meeting. A capability marked supported but yielding no usable content is a failure. For content imports, source preparation happens before the write transaction, then metadata creation, source/chunk commit, and job completion happen atomically. Failures leave no partially queryable meeting and release the reservation.
+
+## Task 3 source integration contract
+
+`createImporter({ prisma, meetingService, clientFactory, sourceService, configService?, audit? })` expects:
+
+- `clientFactory({ connection, config })` to return the client with `listMeetings()` and `getContent()`; `downloadAttachment(url, maxBytes)` must be returned when artifacts require download. The importer passes the complete selected content with attachment buffers and metadata to the source service.
+- `sourceService.prepareImport(content)` to be a pure preparation step with no database writes. It must reject or return no prepared result when content cannot produce usable located source material. The importer also rejects `null` and an empty prepared array.
+- `sourceService.commitImport(tx, meeting, prepared)` to persist sources/chunks inside the transaction supplied by the importer. It must preserve source identity/type and artifact/recording provenance, persist valid nonempty located chunks, and leave the meeting `AVAILABLE` only when indexing is complete. It should throw on empty, malformed, or failed indexing so the transaction rolls back. Prepared-result internal shape is owned by Task 3.
+
+For Tencent content, retain the actual source type (`TENCENT_ORIGINAL`), `externalFileId`, artifact type, and `recordFileId` where applicable. Transcript locations contain `type: "transcript"`, paragraph index, normalized `startMs`/`endMs`, and `recordFileId`. Summary is supplied separately as `summary`; transcript text and located segments are both supplied. Attachment objects contain `name`, `externalFileId`, `sourceType`, `artifactType`, `bytes`, and downloaded `buffer`.
+
+The importer constructs the write-side meeting service with `createMeetingService({ prisma: tx })` so its metadata write participates in the same transaction as source indexing. Task 3 should not add an independent transaction around `commitImport`.
+
+## Schema change
+
+Added nullable `leaseOwner` and `leaseUntil` columns to `meeting_jobs`, plus additive migration `server/prisma/migrations/20261014010000_meeting_job_leases/migration.sql`. These fields make claims exclusive across runners and allow safe restart recovery without relying on in-memory locks. The SQLite client has no `createMany` for the new models, so transaction writes use supported per-row operations.

+  let nextJob = 1;
+  let nextMeeting = 1;
+  let nextSource = 1;
+  const matches = (row, where = {}) => Object.entries(where).every(([key, value]) => {
+    if (value && typeof value === "object" && "in" in value) return value.in.includes(row[key]);
+    if (value && typeof value === "object" && "lte" in value) return row[key] != null && new Date(row[key]) <= value.lte;
+    return row[key] === value;
+  });
+  const delegates = {};
+  for (const collection of Object.keys(state)) delegates[collection] = {
+    findMany: async ({ where = {} } = {}) => state[collection].filter((row) => matches(row, where)),
+    findFirst: async ({ where = {} } = {}) => state[collection].find((row) => matches(row, where)) || null,
+    findUnique: async ({ where = {} } = {}) => state[collection].find((row) => matches(row, where)) || null,
+    create: async ({ data }) => {
+      const id = collection === "meeting_jobs" ? nextJob++ : collection === "meetings" ? nextMeeting++ : nextSource++;
+      const row = { id, createdAt: new Date(), updatedAt: new Date(), ...data };
+      state[collection].push(row);
+      return row;
+    },
+    update: async ({ where, data }) => {
+      const row = state[collection].find((item) => matches(item, where));
+      if (!row) throw new Error("row not found");
+      Object.assign(row, data, { updatedAt: new Date() });
+      return row;
+    },
+    updateMany: async ({ where, data }) => {
+      const rows = state[collection].filter((row) => matches(row, where));
+      rows.forEach((row) => Object.assign(row, data, { updatedAt: new Date() }));
+      return { count: rows.length };
+    },
+  };
+  const db = { ...delegates };
+  db.$transaction = async (callback) => {
+    const snapshot = JSON.parse(JSON.stringify(state));
+    try { return await callback(db); }
+    catch (error) {
+      for (const key of Object.keys(state)) state[key].splice(0, state[key].length, ...snapshot[key]);
+      throw error;
+    }
+  };
+  return { db, state };

+      try {
+        credentials = JSON.parse(await encryption.decrypt(stored.credentials));
+      } catch {
+        throw new MeetingError(
+          "Meeting connection credentials could not be decrypted",
+          "MEETING_CREDENTIALS_UNAVAILABLE",
+          500
+        );
+      }
+    }

+    selectedId = row.id;

+    const settings = stored.settings || {};
+    return {
+      id: row.id,
+      name: row.name,
+      configured: Boolean(stored.credentials),
+      ...(settings.userId ? { userId: settings.userId } : {}),

+        "INVALID_CONNECTION_NAME"

+      if (prior.credentials) {

+          );

+            "MEETING_CREDENTIALS_UNAVAILABLE",

+      : null;

+      "sdkId",
+      "userId",
+      "operatorId",

+      "instanceId",

+function clipContent(content = {}, scope = {}) {
+  const hasRange = scope.from != null || scope.to != null;
+  if (!hasRange) return content;
+  const from = Number(scope.from ?? 0);
+  const to = Number(scope.to);

+    to <= from ||
+    to - from > LIMITS.transcriptDurationMs
+  ) {
+    throw new MeetingError(
+      "Transcript selection must be a positive interval of no more than three hours",
+      "TRANSCRIPT_SCOPE_LIMIT"
+    );

+    (segment) => segment.location?.type === "transcript"

+    (segment) => segment.location?.type !== "transcript"
+  );

+    throw new MeetingError(
+      "Tencent transcript has no timestamps; a time selection cannot be applied",
+      "TRANSCRIPT_TIMESTAMPS_REQUIRED"
+    );

+    const end = Number(segment.location.endMs);

+            },

+        );

+          (reservation) =>
+            reservation.id !== job.id &&
+            (!reservation.activeKey || !activeKeys.has(reservation.activeKey))
+        ).length;
+        if (meetings.length + reserved >= LIMITS.meetingsPerQuarter) {
+          throw new MeetingError(
+            "The quarterly meeting limit has been reached",
+            "MEETING_QUARTER_LIMIT",
+            409
+          );
+        }
+      }
+      try {
+        return await db.meeting_jobs.update({
+          where: { id: job.id },
+          data: {
+            status: "CREATED",
+            activeKey,
+            error: null,
+            stage: null,
+            leaseOwner: null,
+            leaseUntil: null,
+          },
+        });
+      } catch (error) {
+        if (error.code === "P2002")
+          throw new MeetingError(
+            "This meeting import already has an active reservation",
+            "MEETING_DUPLICATE",
+            409
+          );
+        throw error;
+      }
+    });
+  }

+      ticking = true;
+      try {
+        await runOnce();
+      } catch {
+        /* job state records the failure */
+      } finally {
+        ticking = false;
+      }
+    }, pollMs);

+  }

+    if (timer) clearInterval(timer);
+    timer = null;
+  }

+function canonicalSignature({

+  nonce,

+      recordings.push(...(records.record_meetings || []));
+      recordPages = Math.max(recordPages, Number(records.total_page || 1));
+      recordPage += 1;
+    }
+    const matchingRecords = recordings.filter(
+      (item) => String(item.meeting_id) === String(externalId)
+    );
+    const files = matchingRecords
+      .flatMap((item) => item.record_files || [])
+      .sort(
+        (left, right) =>
+          Number(left.record_start_time || 0) -
+          Number(right.record_start_time || 0)
+      );
+    if (
+      files.length > 1 &&
+      files.some((file) => !Number.isFinite(Number(file.record_start_time)))
+    ) {
+      throw new MeetingError(
+        "Tencent did not return recording start times needed to join multiple transcripts",
+        "TENCENT_RECORD_TIMING_MISSING",
+        502
+      );
+    }
+    return { matchingRecords, files, from, to, operatorId, operatorIdType };
+  }
+
+  async function getContent(externalId, scope = {}) {
+    const { files, operatorId, operatorIdType } = await discoverRecord(
+      externalId,
+      scope
+    );
+    const timelineStart = files.length ? Number(files[0].record_start_time) : 0;
+    const transcriptCapability =
+      capabilities.transcript === "supported" ||
+      capabilities.transcript?.status === "supported";
+    const summaryCapability =
+      capabilities.summary === "supported" ||
+      capabilities.summary?.status === "supported";
+    const attachmentCapability =
+      capabilities.attachments === "supported" ||
+      capabilities.attachments?.status === "supported";
+    const result = {
+      summary: null,
+      transcript: null,
+      segments: [],
+      attachments: [],
+      capabilities: {
+        transcript: transcriptCapability
+          ? { status: "supported" }
+          : {
+              status: "unsupported",
+              reason:
+                "Structured transcript retrieval is not enabled for this connection; add transcript text manually if needed.",
+            },
+        summary: summaryCapability
+          ? { status: "supported" }
+          : {
+              status: "unsupported",
+              reason:
+                "Summary retrieval is not enabled for this connection. Add minutes manually if needed.",
+            },
+        attachments: attachmentCapability
+          ? { status: "supported" }
+          : {
+              status: "unsupported",
+              reason:
+                "Recording artifact downloads are not enabled for this connection. Add files manually if needed.",
+            },
+      },
+    };
+    if (!files.length) {
+      result.capabilities.transcript = {
+        status: "absent",
+        reason: "Tencent returned no recording file for this meeting.",
+      };
+      result.capabilities.summary = {
+        status: "absent",
+        reason: "Tencent returned no recording file for this meeting.",
+      };
+      result.capabilities.attachments = {
+        status: "absent",
+        reason: "Tencent returned no recording file for this meeting.",
+      };
+      return result;
+    }
+    for (const file of files) {
+      const fileId = String(file.record_file_id);
+      const fileOffsetMs = Math.max(
+        0,
+        Number(file.record_start_time || timelineStart) - timelineStart
+      );
+      if (transcriptCapability) {
+        const transcriptParams = new URLSearchParams({
+          record_file_id: fileId,
+          meeting_id: String(externalId),
+          operator_id: String(operatorId),
+          operator_id_type: String(operatorIdType),
+        });
+        try {
+          const transcript = await request(
+            `/v1/records/transcripts/details?${transcriptParams}`
+          );
+          const paragraphs = transcript.minutes?.paragraphs || [];
+          const segments = paragraphs
+            .map((paragraph, index) => ({
+              text: (paragraph.sentences || [])
+                .map((sentence) =>
+                  (sentence.words || []).map((word) => word.text || "").join("")
+                )
+                .join(""),
+              location: {
+                type: "transcript",
+                paragraph: Number(paragraph.pid ?? index),
+                startMs: fileOffsetMs + Number(paragraph.start_time),
+                endMs: fileOffsetMs + Number(paragraph.end_time),
+                recordFileId: fileId,
+              },
+            }))
+            .filter((segment) => segment.text.trim());
+          result.segments.push(...segments);
+          result.transcript = result.segments
+            .map((segment) => segment.text)
+            .join("\n");
+          if (!segments.length)
+            result.capabilities.transcript = {
+              status: "absent",
+              reason:
+                "Tencent returned no generated transcript paragraphs for this recording.",
+            };
+        } catch (error) {
+          if (
+            error.code === "TENCENT_API_FAILURE" &&
+            ["30001", "30002", "4049"].includes(error.apiCode)
+          ) {
+            result.capabilities.transcript = {
+              status: "absent",
+              reason:
+                "Tencent returned no generated transcript for this recording.",
+            };
+          } else throw error;
+        }
+      }
+      if (summaryCapability) {
+        const minuteParams = new URLSearchParams({
+          operator_id_type: String(operatorIdType),
+          operator_id: String(operatorId),
+          minute_type: "0",
+          text_type: "1",
+        });
+        const minute = await request(
+          `/v1/smart/minutes/${encodeURIComponent(fileId)}?${minuteParams}`
+        );
+        result.summary = minute.meeting_minute?.minute || null;
+        if (!result.summary)
+          result.capabilities.summary = {
+            status: "absent",
+            reason:
+              "Tencent returned no generated smart minutes for this recording.",
+          };
+      }
+      if (attachmentCapability) {
+        const detailParams = new URLSearchParams({
+          operator_id: String(operatorId),
+          operator_id_type: String(operatorIdType),
+        });
+        const detail = await request(
+          `/v1/addresses/${encodeURIComponent(fileId)}?${detailParams}`
+        );
+        for (const type of [
+          "meeting_summary",
+          "ai_meeting_transcripts",
+          "ai_minutes",
+          "ai_topic_minutes",
+          "ai_speaker_minutes",
+          "ai_ds_minutes",
+        ]) {
+          for (const artifact of detail[type] || []) {
+            if (!artifact.download_address) continue;
+            result.attachments.push({
+              name: `${fileId}.${String(artifact.file_type || "txt")}`,
+              downloadUrl: artifact.download_address,
+              externalFileId: `${fileId}:${type}:${artifact.file_type || "txt"}`,
+              sourceType: "TENCENT_ORIGINAL",
+              artifactType: type,
+            });
+          }
+        }
+      }
+    }
+    return result;
+  }
+
+  async function describeMeeting(externalId, range = {}) {
+    const { matchingRecords, files, operatorId, operatorIdType } =
+      await discoverRecord(externalId, range);
+    const transcriptEnabled =
+      capabilities.transcript === "supported" ||
+      capabilities.transcript?.status === "supported";
+    const summaryEnabled =
+      capabilities.summary === "supported" ||
+      capabilities.summary?.status === "supported";
+    const attachmentEnabled =
+      capabilities.attachments === "supported" ||
+      capabilities.attachments?.status === "supported";
+    const manifest = {
+      attachments: [],
+      transcriptDurationMs: files.reduce(
+        (maximum, file) =>
+          Math.max(
+            maximum,
+            Number(file.record_end_time || 0) -
+              Number(files[0]?.record_start_time || file.record_start_time || 0)
+          ),
+        0
+      ),
+      recordings: files.map((file) => ({
+        recordFileId: String(file.record_file_id),
+        startOffsetMs:
+          Number(file.record_start_time || files[0]?.record_start_time || 0) -
+          Number(files[0]?.record_start_time || file.record_start_time || 0),
+        durationMs: Math.max(
+          0,
+          Number(file.record_end_time || 0) -
+            Number(file.record_start_time || 0)
+        ),
+      })),
+      capabilities: {
+        transcript: transcriptEnabled
+          ? { status: files.length ? "supported" : "absent" }
+          : {
+              status: "unsupported",
+              reason:
+                "Structured transcript retrieval is not enabled for this connection.",
+            },
+        summary: summaryEnabled
+          ? { status: files.length ? "supported" : "absent" }
+          : {
+              status: "unsupported",
+              reason: "Summary retrieval is not enabled for this connection.",
+            },
+        attachments: attachmentEnabled
+          ? { status: files.length ? "supported" : "absent" }
+          : {
+              status: "unsupported",
+              reason:
+                "Recording artifact downloads are not enabled for this connection.",
+            },
+      },
+    };
+    if (!matchingRecords.length) return manifest;
+    if (attachmentEnabled) {
+      for (const file of files) {
+        const params = new URLSearchParams({
+          operator_id: String(operatorId),
+          operator_id_type: String(operatorIdType),
+        });
+        const detail = await request(
+          `/v1/addresses/${encodeURIComponent(file.record_file_id)}?${params}`
+        );
+        for (const type of [
+          "meeting_summary",
+          "ai_meeting_transcripts",
+          "ai_minutes",
+          "ai_topic_minutes",
+          "ai_speaker_minutes",
+          "ai_ds_minutes",
+        ]) {
+          for (const artifact of detail[type] || []) {
+            if (!artifact.download_address) continue;
+            const fileType = String(artifact.file_type || "txt");
+            manifest.attachments.push({
+              externalFileId: `${file.record_file_id}:${type}:${fileType}`,
+              name: `${file.record_file_id}.${fileType}`,
+              sourceType: "TENCENT_ORIGINAL",
+              artifactType: type,
+              bytes: null,
+              maxBytes: MAX_FILE_BYTES,
+            });
+          }
+        }
+      }
+    }
+    return manifest;
+  }
+
+  async function downloadAttachment(downloadUrl, maxBytes = MAX_FILE_BYTES) {
+    const response = await request("/", {
+      urlOverride: downloadUrl,
+      download: true,
+    });
+    const advertised = Number(response.headers?.get?.("content-length"));
+    if (Number.isFinite(advertised) && advertised > maxBytes)
+      throw new MeetingError(
+        "Tencent artifact exceeds the 100 MB file limit",
+        "FILE_SIZE_LIMIT",
+        413
+      );
+    if (!response.body?.getReader) {
+      const buffer = Buffer.from(await response.arrayBuffer());
+      if (buffer.length > maxBytes)
+        throw new MeetingError(
+          "Tencent artifact exceeds the 100 MB file limit",
+          "FILE_SIZE_LIMIT",
+          413
+        );
+      return buffer;
+    }
+    const reader = response.body.getReader();
+    const chunks = [];
+    let total = 0;
+    while (true) {
+      const { done, value } = await reader.read();
+      if (done) break;
+      total += value.byteLength;
+      if (total > maxBytes) {
+        await reader.cancel();
+        throw new MeetingError(
+          "Tencent artifact exceeds the 100 MB file limit",
+          "FILE_SIZE_LIMIT",
+          413
+        );
+      }
+      chunks.push(Buffer.from(value));
+    }
+    return Buffer.concat(chunks, total);
+  }
+
+  return { listMeetings, getContent, describeMeeting, downloadAttachment };
+}
